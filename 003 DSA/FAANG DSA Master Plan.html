↳ Pattern #5 — Binary Search on Answer
lo = 0, hi = n-1 while lo <= hi: mid = lo + (hi - lo) // 2 if condition: hi = mid - 1 else: lo = mid + 1
Instead of searching for an element, search for the answer itself. Allocate Minimum Pages and Aggressive Cows are the canonical examples. This unlocks a whole class of hard problems.

def backtrack(state, choices): if goal reached: add state to results; return for choice in choices: make choice backtrack(updated state, updated choices) undo choice ← this is the "back"
Identify state, choices, and goal before writing any code. These three are all that change.
